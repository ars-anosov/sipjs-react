sipjs-react

WebRTC-телефон: SIP-клиент на sip.js, видеовстречи на LiveKit и авторизация через Active Directory.

  • Диаграмма архитектуры (archify)
    Интерактивная схема: UI → Redux → services → sip.js и мост AD → LiveKit.
  • SIP-регистрация (archify, sequence)
    Путь клика по тумблеру AuthPad: handleClkRegister → phoneRuntime → Registerer, успех / отказ, авто-останов и разрегистрация; regState — off / ok / fail.
  • Mermaid-схемы (STATE.md)
    Слой стора и Redux, регистрация, звонки и чат.
Исходники: github.com/ars-anosov/sipjs-react
